## 第一部分：用户使用手册

### 1. 环境准备与启动方式

- **环境要求**：Python `>= 3.12`；如需 Excel `.xlsx` 导入导出需安装 `openpyxl>=3.1`（GUI 依赖 Python 标准库 `tkinter`）。
- **三种使用方式**：
  1. **桌面图形客户端（推荐，全中文界面）**：
     ```bash
     python -m txtsql --gui [--dir ./my_data]
     # 或安装后直接执行：txtsql-gui
     ```
  2. **命令行交互终端（CLI）**：
     ```bash
     python -m txtsql [--dir ./my_data]
     # 或：txtsql
     ```
     支持多行输入，以 `;` 结尾执行；输入 `exit` / `quit` 退出。
  3. **Python 嵌入式调用 API**：
     ```python
     from txtsql import Database

     db = Database("./my_data", enable_optimizations=True)
     res = db.execute("SELECT * FROM demo ORDER BY id;")
     print(res.columns, res.rows)
     ```

### 2. Tkinter 图形客户端操作指南

- **主界面分区**：
  - **顶部工具栏**：数据目录显示与切换、常用执行按钮（运行当前 / 剖析计划 / 运行全部 / 运行选中 / 清空）、Excel 导入与结果导出；
  - **左侧数据表浏览器**：按表名实时筛选、展示表与字段类型及 `⚡ 索引`、右键支持「预览前 100 行」「`DESCRIBE`」「插入表名」「`DROP TABLE`」、点击 `+ 新建表` 可视化建表；
  - **右上方 SQL 编辑器**：
    - 同步行号、防抖语法高亮、历史快速回填下拉框；
    - **当前语句高亮框选（IDEA 风格）**：光标所在 SQL 语句的所有行自动铺设浅蓝背景，按 **`Ctrl+Enter`** 仅执行当前语句，**`F5`** 执行编辑器全部语句；
    - **实时代码补全**：输入 `表名.` / `别名.`、`FROM`/`JOIN`/`UPDATE` 后表名或关键字/字段前缀自动弹出候选列表，可用 **`Ctrl+Space`** 手动唤出，`Tab` / `Enter` / 点击插入；
  - **右下方五页签**：
    1. **查询结果**：`<NULL>` 区分空字符串、自适应列宽、点击列头升降序（保持列宽）、双击单元格查看多行全文、右键复制整行；
    2. **执行消息**：逐条显示成功/失败摘要与毫秒级耗时；
    3. **历史记录**：双击历史记录快速回填编辑器；
    4. **系统日志**：实时输出运行日志并支持 `DEBUG`/`INFO`/`WARNING` 级别动态切换；
    5. **执行计划与可视化**：按 **`Ctrl+E`** 或工具栏 `🔍 剖析计划`，自动运行 `EXPLAIN ANALYZE` 并渲染算子流水线画布、指标明细表及词法 Token / AST 透视树。
  - **底部状态栏**：左侧展示目录路径、表数量及 `[事务中]` 状态提示，右侧展示执行摘要与光标行列号。

- **快捷键汇总**：

| 快捷键 | 功能说明 |
|---|---|
| `Ctrl+Enter` | 运行光标所在当前高亮 SQL 语句 |
| `Ctrl+E` | 剖析当前高亮语句执行计划（`EXPLAIN ANALYZE`） |
| `F5` | 运行编辑器中全部 SQL 语句 |
| `Ctrl+Shift+Enter` | 仅运行鼠标选中的 SQL 语句 |
| `Ctrl+Space` | 手动弹出上下文 SQL 代码补全列表 |
| `Tab` / `Enter` / `↑↓` / `Esc` | 补全列表确认、切换与关闭 |
| `Ctrl+O` / `Ctrl+S` / `Ctrl+L` / `Ctrl+Q` | 切换数据目录 / 保存脚本 / 清空编辑器 / 退出 |

- **内置示例模板**：菜单「示例模板」内置 5 套端到端演示脚本，覆盖单表 CRUD、分组统计与聚合、多表 JOIN、子查询与 UNION、索引与 `EXPLAIN ANALYZE` 执行剖析。

### 3. 常用新特性 SQL 速查

```sql
-- 1. 创建与管理二级索引
CREATE INDEX IF NOT EXISTS idx_emp_dept ON emp (dept_id);
SHOW INDEXES FROM emp;
DROP INDEX IF EXISTS idx_emp_dept;

-- 2. 白盒执行计划与运行时指标剖析
EXPLAIN SELECT e.name, d.dname FROM emp e JOIN dept d ON e.dept_id = d.id;
EXPLAIN ANALYZE SELECT * FROM emp WHERE salary BETWEEN 8000 AND 15000;

-- 3. 纯文本 TSV 文件完整性审计（外部编辑后检查损坏行号）
CHECK TABLE emp;

-- 4. 目录级快照事务
BEGIN TRANSACTION;
UPDATE emp SET salary = salary * 1.1 WHERE dept_id = 10;
ROLLBACK;  -- 或 COMMIT;
```

### 2. 性能优化基准测试
