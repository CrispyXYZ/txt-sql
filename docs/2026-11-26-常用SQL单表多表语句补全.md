## 一、新增与补全的功能清单（共 10 项）

### 1. 逻辑前缀 `NOT`
- 在词法/语法优先级链 `OR < AND < NOT < 比较/谓词` 中加入前缀 `NOT`（`NotExpression`），严格遵循 SQL 三值逻辑：`NOT TRUE -> False`、`NOT FALSE -> True`、`NOT UNKNOWN -> UNKNOWN`；`NOT EXISTS (...)` 与 `NOT` 组合均保持兼容。

### 2. `IN (expr1, expr2, ...)` 与 `NOT IN (...)` 常量/表达式列表
- 新增 `InListExpression`，支持逗号分隔的多表达式列表（如 `WHERE id IN (1, 1 + 2)`），并与 `InExpression` 子查询共用统一的三值逻辑求值器 `_eval_in_values()`，正确处理列表含 `NULL` 时的 `NOT IN` 语义。

### 3. `BETWEEN low AND high` 与 `NOT BETWEEN`
- 新增 `BetweenExpression`，上下界采用 `parse_add()` 解析，避免 `BETWEEN` 中的 `AND` 与外层逻辑 `AND` 冲突。
- 严格按 `(expr >= low) AND (expr <= high)` 的三值逻辑计算（例如 `5 BETWEEN NULL AND 3` 为 `False`，其 `NOT BETWEEN` 为 `True`）。

### 4. `LIKE pattern` 与 `NOT LIKE`
- 新增 `LikeExpression`，支持 SQL 通配符 `%`（任意长度字符，含 `re.DOTALL` 多行匹配）与 `_`（单字符），并对正则元字符（`.`、`[`、`]`、`+` 等）自动转义；含 `NULL` 返回 `UNKNOWN`，非字符串类型抛出 `TypeMismatchError`。

### 5. `UPDATE t SET col = expr`（表达式与子查询赋值）
- 将 `UpdateStatement.set_clauses` 升级为通用 `Expression`（禁止聚合函数），并在 `storage.Table` 新增 `update_rows(updater, where)`，基于原行数据逐列求值（支持 `SET salary = salary * 1.1, bonus = salary / 10` 及标量子查询），全部行校验通过后一次性原子写回；字面量类型错误在命中 0 行时也可提前拦截。

### 6. `INSERT INTO t [(cols)] SELECT ...`
- 新增 `InsertSelect` 语句节点，支持将 `SELECT` 或 `UNION` 结果写入目标表（含指定列与省略列默认 `NULL`）；执行前先完整物化源查询结果以防止自表插入死循环，并校验列数与数据类型一致性。

### 7. `CREATE TABLE IF NOT EXISTS` 与 `DROP TABLE IF EXISTS`
- 在词法新增 `IF` 关键字，支持幂等建表与删表，方便初始化脚本与 GUI 演示脚本重复执行。

### 8. `SELECT table.*` 多表通配符展开
- 新增 `StarExpression(table)`，支持 `SELECT a.*, b.score`、`SELECT a.*, b.*`、`SELECT t.*, id * 2` 等混合列投影；同名列自动保留 `table.col` 限定符，未知表名/别名抛出 `TableNotFoundError`，禁止与 `GROUP BY`/聚合混用，且 0 行结果仍完整保留 `QueryResult.columns`。

### 9. 标量子查询 `(SELECT ...)`
- 新增 `ScalarSubqueryExpression`，支持在 `WHERE`、`SELECT` 列表、`UPDATE SET` 及算术表达式中使用非关联/关联标量子查询；0 行返回 `None`（`NULL`），超过 1 行或列数不为 1 抛出 `EngineError`。

### 10. `COUNT(DISTINCT col)` 等去重聚合
- 为 `AggregateExpression` 增加 `distinct: bool`，支持 `COUNT(DISTINCT col)` 及 `SUM`/`AVG`/`MIN`/`MAX(DISTINCT col)`；对 `NULL` 自动忽略、对 `Decimal('1')` 与 `Decimal('1.0')` 正确去重，拒绝非法的 `COUNT(DISTINCT *)`。
