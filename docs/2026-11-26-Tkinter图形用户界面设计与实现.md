## 一、架构设计与模块解耦

为避免界面逻辑与数据控制耦合、确保无显示器 CI 环境下仍可自动化测试，GUI 拆分为两层：

1. **纯 Python 控制层（[gui_controller.py](file:///home/crispyxyz/PycharmProjects/txt-sql/txtsql/gui_controller.py)）**：
   - 零 `tkinter` 依赖，直接持有 `Database(data_dir)` 并消费结构化 `QueryResult`。
   - 提供 `find_statement_spans()` / `split_sql_statements()` / `find_active_statement()`（按文本字符位置识别每条可执行语句的起止范围，安全忽略字符串字面量与 `--` 注释内的分号，并精准定位光标所在的当前语句 `StatementSpan`）。
   - 提供实时上下文代码补全引擎：`CompletionItem` / `CompletionResult` 与 `GuiController.get_completions()`，支持 `table.` / `alias.` 限定列名补全、`FROM` / `JOIN` / `INTO` / `UPDATE` / `DESCRIBE` / `TABLE` / `IMPORT` 上下文的实时表名补全，以及通用上下文优先级排序（当前语句关联列 > 聚合函数 > SQL 关键字 > 表名 > 其他表列），并在字符串字面量与 `--` 注释内自动静默。
   - 提供 `format_cell_display()` / `format_cell_single_line()`（将 `NULL` 显示为 `<NULL>`，空字符串 `''` 显示为空白）、`build_create_table_sql()`（建表向导校验与生成）、`sort_rows_for_view()`（视图列头排序且 `NULL` 置后）。
   - 提供 `GuiController` 状态管理器（目录切换隔离、批量脚本执行与耗时统计、`explain_sql()` 剖析入口、历史记录、`IMPORT`/`EXPORT` 封装）及 5 套可一键加载运行的中文示例模板 `DEMO_TEMPLATES`。
2. **Tkinter 视图层（[gui.py](file:///home/crispyxyz/PycharmProjects/txt-sql/txtsql/gui.py)）**：
   - `TxtSqlApp` 主窗体（自适应 HiDPI 缩放与最小尺寸约束，`clam` 主题，全中文界面）、`CreateTableDialog` 可视化建表弹窗、`ImportTableDialog` Excel 导入弹窗、`_TkLogHandler` 实时日志转发器。

## 二、窗体功能与交互清单

- **菜单栏与工具栏**：
  - `文件`（切换数据目录 `Ctrl+O`、打开/保存 `.sql` 脚本 `Ctrl+S`、导入 Excel `.xlsx`、导出结果 `.xlsx`/`.csv`/`.tsv`、退出 `Ctrl+Q`）；
  - `执行`（**方案 A**：运行当前高亮语句 `Ctrl+Enter`、剖析执行计划 `Ctrl+E`、运行全部 `F5`、运行选中 `Ctrl+Shift+Enter`、触发代码补全 `Ctrl+Space`、清空编辑器 `Ctrl+L`）；
  - `示例模板`（一键加载单表 CRUD、分组统计与聚合、多表 JOIN、子查询与 UNION、索引与 `EXPLAIN ANALYZE` 演示脚本）；
  - `帮助`（快捷键与 SQL 速查、关于）。
- **左侧数据表浏览器（`ttk.Treeview`）**：
  - 展示表名、行数、字段 `列名 : 类型` 与 `⚡ 索引: idx_name (col)`；支持实时名称筛选、`+ 新建表` 弹窗；
  - 双击表名预览前 100 行，右键支持预览、`DESCRIBE`、插入表名及带确认的 `DROP TABLE`。
- **右上方 SQL 编辑器（IDEA 风格当前语句高亮 + 实时代码补全）**：
  - 同步行号栏、多行等宽字体、`Tab` 四空格缩进、撤销/重做、防抖 SQL 语法高亮（关键字、字符串、数字、`--` 注释）及历史快速回填下拉框；
  - **当前语句高亮框选**：光标所在可执行语句的所有整行自动铺设柔和浅蓝背景（`#eaf3ff`），左侧行号同步蓝色加粗高亮，搭配 `Ctrl+Enter` 直接执行或 `Ctrl+E` 一键剖析该语句；
  - **实时代码补全弹窗**：输入标识符或 `.` 后自动在光标下方/上方弹出上下文候选列表（`Ctrl+Space` 可手动唤出），支持 `↑`/`↓` 选择、`Tab`/`Enter`/鼠标点击插入、`Esc` 关闭。
- **右下方五页签（`ttk.Notebook`）**：
  - `查询结果`：斑马纹表格，表头与列宽按字体测量自适应内容且点击列头排序后保持自定义列宽，0 行结果依然保留表头，`<NULL>` 与空字符串直观区分，支持升/降序排列、双击单元格查看/复制完整多行文本、右键复制整行。
  - `执行消息`：按时间彩色展示每条语句执行摘要、受影响行数、耗时（ms）与精确错误提示。
  - `历史记录`：记录时间、状态、耗时与 SQL，双击回填到编辑器。
  - `系统日志`：实时显示 `txtsql` 运行日志，支持在 `DEBUG` / `INFO` / `WARNING` 间动态切换。
  - `执行计划与可视化`：内含 **算子流水线视图（`tk.Canvas`）**（彩色算子卡片、优化徽章、行数衰减箭头与耗时占比条）、**算子指标明细（`ttk.Treeview`）** 以及 **词法 Token 与 AST 透视树**。
- **底部状态栏**：显示当前目录、表数量、事务状态 `[事务中]`、最近一次执行摘要与光标行列号。
