## 一、架构设计与模块解耦

为避免界面逻辑与数据控制耦合、确保无显示器 CI 环境下仍可自动化测试，GUI 拆分为两层：

1. **纯 Python 控制层（[gui_controller.py](file:///home/crispyxyz/PycharmProjects/txt-sql/txtsql/gui_controller.py)）**：
   - 零 `tkinter` 依赖，直接持有 `Database(data_dir)` 并消费结构化 `QueryResult`。
   - 提供 `split_sql_statements()`（安全忽略字符串字面量与 `--` 注释内的分号）、`format_cell_display()` / `format_cell_single_line()`（将 `NULL` 显示为 `<NULL>`，空字符串 `''` 显示为空白）、`build_create_table_sql()`（建表向导校验与生成）、`sort_rows_for_view()`（视图列头排序且 `NULL` 置后）。
   - 提供 `GuiController` 状态管理器（目录切换隔离、批量脚本执行与耗时统计、历史记录、`IMPORT`/`EXPORT` 封装）及 4 套可一键加载运行的中文示例模板 `DEMO_TEMPLATES`。
2. **Tkinter 视图层（[gui.py](file:///home/crispyxyz/PycharmProjects/txt-sql/txtsql/gui.py)）**：
   - `TxtSqlApp` 主窗体（默认 `1160×740`，`clam` 主题，全中文界面）、`CreateTableDialog` 可视化建表弹窗、`_TkLogHandler` 实时日志转发器。

## 二、窗体功能与交互清单

- **菜单栏与工具栏**：
  - `文件`（切换数据目录 `Ctrl+O`、打开/保存 `.sql` 脚本 `Ctrl+S`、导入 Excel `.xlsx`、导出结果 `.xlsx`/`.csv`/`.tsv`、退出 `Ctrl+Q`）；
  - `执行`（运行全部 `F5`/`Ctrl+Enter`、运行选中 `Ctrl+Shift+Enter`、清空编辑器 `Ctrl+L`）；
  - `示例模板`（一键加载单表 CRUD、分组统计与聚合、多表 JOIN、子查询与 UNION 演示脚本）；
  - `帮助`（快捷键与 SQL 速查、关于）。
- **左侧数据表浏览器（`ttk.Treeview`）**：
  - 展示表名、行数及展开字段 `列名 : 类型`；支持实时名称筛选、`+ 新建表` 弹窗；
  - 双击表名预览前 100 行，右键支持预览、`DESCRIBE`、插入表名及带确认的 `DROP TABLE`。
- **右上方 SQL 编辑器**：
  - 同步行号栏、多行等宽字体、`Tab` 四空格缩进、撤销/重做、防抖 SQL 语法高亮（关键字、字符串、数字、`--` 注释）及历史快速回填下拉框。
- **右下方四页签（`ttk.Notebook`）**：
  - `查询结果`：斑马纹表格，0 行结果依然保留表头，`<NULL>` 与空字符串直观区分，支持点击列头升/降序排列、双击单元格查看/复制完整多行文本、右键复制整行。
  - `执行消息`：按时间彩色展示每条语句执行摘要、受影响行数、耗时（ms）与精确错误提示。
  - `历史记录`：记录时间、状态、耗时与 SQL，双击回填到编辑器。
  - `系统日志`：实时显示 `txtsql` 运行日志，支持在 `DEBUG` / `INFO` / `WARNING` 间动态切换。
- **底部状态栏**：显示当前目录与表数量、最近一次执行摘要与光标行列号。
