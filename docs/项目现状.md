## 三、已完成内容详述

### 1. 后端 SQL 全链路与常用单表/多表能力（已提交至 `dev`）

- **清晰且高内聚的模块组织**：
  - 接口与编排：`engine.py`（`Database` 会话与 `execute_sql` 兼容入口）、`result.py`（`QueryResult` / `StatementKind`）、`cli.py`（REPL）
  - 语言解析：`lexer.py` → `parser.py` + `ast.py`（含共享 AST 遍历辅助函数）
  - 执行与求值：`executor.py`（`QueryExecutor`）+ `evaluator.py`（`EvalContext` 与公开求值 API）+ `io_handlers.py`（Excel/CSV/TSV 读写）
  - 存储与基础类型：`storage.py`（目录级 `StorageEngine` 与 `Table`）、`types.py`、`exceptions.py`
- **完整 SQL 能力与数据语义**：
  - 严格区分 `NULL`（`\N` 哨兵）与空字符串 `''`，安全支持 `\t`、`\n`、引号和反斜杠；`TRUE`/`FALSE` 等价为 `NUMBER` `1`/`0`；完整 SQL 三值逻辑（3VL）。
  - DDL/DML：`CREATE TABLE [IF NOT EXISTS]`、`DROP TABLE [IF EXISTS]`、`INSERT INTO ... VALUES`、`INSERT INTO ... SELECT`、`UPDATE ... SET col = expr`、`DELETE`。
  - 谓词与子查询：`NOT`、`IN (list/subquery)`、`BETWEEN ... AND ...`、`LIKE`（`%`/`_`）、`IS [NOT] NULL`、`ANY`/`ALL`、`EXISTS`/`NOT EXISTS` 与标量子查询（含关联）。
  - 查询与多表：单表/多表全类型 `JOIN`、`SELECT table.*`、`GROUP BY`/`HAVING`/`ORDER BY`/`LIMIT`/`OFFSET`/`DISTINCT`、`COUNT(DISTINCT col)` 以及 `UNION`/`UNION ALL`。
  - 多 `Database(data_dir)` 实例彻底脱离全局 `os.getcwd()`，可直接支持 GUI 多工作目录切换与表结构浏览；`QueryResult` 在 0 行结果集下依然保留 `columns`。
- **自动化测试覆盖**：`tests/test_cli.py`（16 项）、`tests/test_database_api.py`（6 项）与 `tests/test_engine.py`（158 项）共计 **180 项测试全部通过**。
