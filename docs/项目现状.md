## 三、已完成内容详述

### 1. 软件原型全部核心功能（已提交至 `dev`）

- **后端全链路与深化架构**：
  - 接口与编排：`engine.py`（`Database` 与 `execute_sql`）、`result.py`（`QueryResult` / `StatementKind`）
  - 语言解析：`lexer.py` → `parser.py` + `ast.py`（共享 AST 遍历辅助）
  - 执行与求值：`executor.py`（`QueryExecutor`）+ `evaluator.py`（`EvalContext` 与公开求值 API）+ `io_handlers.py`（`.xlsx`/`.csv`/`.tsv` 导入导出）
  - 存储与基础类型：`storage.py`（目录级 `StorageEngine` 与 `Table`）、`types.py`、`exceptions.py`
- **双交互界面**：
  - **CLI（`txtsql` / `python -m txtsql`）**：多行分号 REPL 与 ASCII 表格渲染。
  - **GUI（`txtsql-gui` / `python -m txtsql --gui`）**：基于 Tkinter/ttk 的全中文桌面客户端，支持数据目录切换、表浏览与建表向导、行号与语法高亮、当前高亮语句定位执行（`Ctrl+Enter`）、实时上下文 SQL 代码补全、自适应列宽结果表（`<NULL>` 区分空串、点击排序保持列宽、详情弹窗）、执行消息、历史回填、实时系统日志、Excel 导入导出及 4 套内置演示模板。
- **自动化测试覆盖**：`tests/test_cli.py`（16 项）、`tests/test_database_api.py`（6 项）、`tests/test_engine.py`（159 项）与 `tests/test_gui_controller.py`（17 项）共计 **198 项测试全部通过**。
