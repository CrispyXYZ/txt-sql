## 三、已完成内容详述

### 1. 后端 SQL 全链路（已修复、补全测试并提交至 `dev`）

- **五层清晰架构**：存储引擎层（`storage.py`）→ 语言解析层（`lexer.py`、`parser.py`、`ast.py`）→ 执行层（`executor.py`、`evaluator.py`）→ 编排层（`engine.py`）→ 用户接口层（`cli.py`），配合 `types.py` 与 `exceptions.py`。
- **数据存储与持久化**：
  - `metadata.txt` 管理表结构元数据，`<table_name>.txt` 以 TSV（`csv.QUOTE_ALL`）保存行数据，所有写操作（含 `DROP TABLE` 更新 `metadata.txt`）均采用临时文件 + `os.replace` 原子落盘。
  - 采用 `\N` 哨兵 + 反斜杠转义（`\\`）严格区分 SQL `NULL` 与空字符串 `''`，同时安全支持含 `\t`、`\n`、引号和字面量 `\N` 的字符串。
  - 数值使用 `Decimal` 避免浮点精度误差；支持 `STRING`/`NUMBER` 类型（词法层兼容 `VARCHAR`/`DECIMAL`/`INT` 别名）；`TRUE`/`FALSE` 等价为 `NUMBER` 的 `1`/`0`，可写入 `NUMBER` 列及参与算术/比较。
- **完整 SQL 语句与查询能力**：
  - DDL / DML：`CREATE TABLE`、`DROP TABLE`、`INSERT INTO ... VALUES`（单行/多行原子批量校验/指定列/负数）、`UPDATE ... SET ... [WHERE]`、`DELETE FROM ... [WHERE]`（`UPDATE`/`DELETE` 的 `WHERE` 均支持子查询）。
  - 单表与聚合：`SELECT [DISTINCT]`、`WHERE`（SQL 三值逻辑 `AND`/`OR`、`IS [NOT] NULL`、`=`/`<>`/`!=`/`>`/`<`/`>=`/`<=`、算术运算）、`GROUP BY`（支持 `table.col` 及无聚合分组）、`HAVING`（支持别名与直接聚合函数）、`COUNT(*)`/`COUNT`/`SUM`/`AVG`/`MIN`/`MAX`（可选 `AS` 别名及聚合算术表达式）、`ORDER BY`（支持 `table.col` 与非投影列排序、`NULL` 置后）、`LIMIT` / `OFFSET`。
  - 多表连接：`FROM a, b`、`CROSS JOIN`、`[INNER] JOIN`、`LEFT/RIGHT/FULL [OUTER] JOIN`、`ON`、`USING`、`NATURAL JOIN`、表别名、自连接。
  - 子查询与集合操作：`IN`、`NOT IN`、`ANY`、`ALL`、`EXISTS`、`NOT EXISTS`（含关联外层行引用）以及 `UNION` / `UNION ALL`。
  - 词法扩展：单引号转义 `''`、`--` 单行 SQL 注释。
- **交互式 CLI 与扩展命令**：
  - `cli.py` 支持多行分号输入、ASCII 边框表格输出（`None` 渲染为空白）、系统命令 `SHOW TABLES` 与 `DESCRIBE`。
  - 支持 `IMPORT`（`.xlsx` 自动类型推断或显式列定义，失败自动回滚）与 `INTO OUTFILE`（`.xlsx`/`.csv`/`.tsv`）。
- **自动化测试覆盖**：`tests/test_cli.py`（16 项）与 `tests/test_engine.py`（149 项）共计 **165 项测试全部通过**。
